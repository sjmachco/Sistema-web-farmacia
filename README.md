Sistema web para una farmacia<br>
-Descripción:<br>
Este sistema web dinámico cuenta con varios módulos, cada uno<br>
de ellos con diferentes requisitos, campos y<br>
funcionalidades.<br>
Al ejecutar el sistema este muestra una pantalla de login<br>
que permite logearse a los usuarios que anteriormente<br>
ya han sido registrados por el usuario "admin".<br>
Tiene un requisito de permisos, donde solo el usuario<br>
"admin" podrá visualizar el módulo usuario/empleado<br>
y realizar las funcionalidades que este contiene.<br>
Los empleados podran hacer uso de todos los módulos, excepto<br>
el del usuario/empleados.<br>
Módulo menú principal:<br>
-Funcionalidad:<br>
Muestra información del usuario logeado.<br>


Módulo usuario:<br>
-Funcionalidad:<br>
Muestra un formulario donde permite registrar datos<br>
del usuario/empleado.<br>
Muestra un boton actualizar que permite modificar<br>
los datos requeridos.<br>
Muestra un boton eliminar que permite borrar<br>
los datos requeridos.<br>
Muestra un buscador que permite encontrar los datos<br>
requeridos.<br>
Valida el usuario registrado, por ese motivo no puede<br>
existir usuarios duplicados.<br>
