<h1>Sistema web para una farmacia</h1>
---Descripción:<br>
-Este sistema web dinámico cuenta con varios módulos, cada uno de ellos con diferentes requisitos, campos y funcionalidades.<br>
-Al ejecutar el sistema este muestra una pantalla de login que permite logearse a los usuarios que anteriormente ya han sido registrados por el usuario "admin".<br>
-Tiene un requisito de permisos, donde solo el usuario "admin" podrá visualizar el módulo usuario/empleado y realizar las funcionalidades que este contiene.<br>
-Los empleados podran hacer uso de todos los módulos, excepto el del usuario/empleados.<br>
---Módulo menú principal---<br>
--Funcionalidad:<br>
-Muestra información del usuario logeado.<br>


---Módulo usuario---<br>
--Funcionalidad:<br>
-Muestra un formulario donde permite registrar datos del usuario/empleado.<br>
-Muestra un boton actualizar que permite modificar los datos requeridos.<br>
-Muestra un boton eliminar que permite borrar los datos requeridos.<br>
-Muestra un buscador que permite encontrar los datos requeridos.<br>
-Valida el usuario registrado, por ese motivo no puede existir usuarios duplicados.<br>
